# 物理世界奇遇记

一款以物理知识点为主题的 2D 平台解谜游戏。当前版本已经有可运行的框架、地图式章节选择、MC 式底部 HUD、本地存档、管理员模式、关卡引擎和第 1 章 9 关真实可玩内容。

## 运行

在项目根目录启动一个静态服务器：

```powershell
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

也可以直接双击 `index.html` 运行，但部分浏览器对本地文件加载脚本有限制，建议使用本地服务器。

项目目录内还有一个 Node 静态服务器：

```powershell
node server.js
```

## 操作

- `A / D`：左右移动
- `W / 空格`：跳跃
- `S`：潜行 / 下蹲
- `E`：互动
- `Q`：使用当前道具
- `1-6 / Z / X / 鼠标滚轮`：切换物品栏
- `R`：重置到检查点
- `Esc / P`：暂停

双人模式按键已预留架构，后续接入。

## 管理员模式

标题画面右下角有“管理员模式”按钮。验证密码后：

- 解锁全部章节和关卡
- 章节地图显示全部内容
- 可以不受正常解锁顺序限制，任意选择关卡浏览

密码输入会忽略全角/半角差异、大小写和空格，避免输入法状态造成干扰。

## 开发调试

运行自动试玩测试，会通过无头浏览器逐关模拟按键，检查关卡是否可完成：

```powershell
node test/playtest.mjs
```

只测试某一关：

```powershell
node test/playtest.mjs 1-1
```

常用深链：

- `#chapters`：直接打开维度地图
- `#level=1:1-1`：直接打开指定关卡

## 文件结构

```text
index.html         入口页面与界面结构
css/style.css      emil-design-eng 风格视觉系统
js/data.js         章节、关卡槽位、终章数据
js/save.js         本地存档、进度解锁、管理员验证
js/input.js        键盘与鼠标输入系统
js/ui.js           标题、章节地图、关卡列表、HUD 渲染
js/levels.js       第 1 章关卡数据与通用关卡生成
js/runtime.js      关卡引擎与环境背景
js/app.js          状态机与主循环
test/playtest.mjs  自动化试玩测试
docs/DESIGN.md     已确定的设计文档
```

- 每个章节有关卡槽位，其他章节使用可玩的通用生成关卡
- 本地进度、管理员模式、隐藏章节解锁规则已实现
- 第 1 章 9 关已填充真实关卡内容
- 关卡引擎支持平台、冰面、沙地、斜面、弹簧、弹射台、移动平台、重力区、箱子、开关、门、尖刺、敌人和章节 Boss
- 游戏 HUD 模仿 MC 布局但采用非像素风格：底部生命条与 6 格物品栏
- 标题界面提供简单 / 完整 / 炼狱三种难度选择
- 纪念品商店可以消耗法则能量购买纪念品与角色皮肤
- 波尔角色已重新设计为圆润的兜帽特工造型，并支持皮肤换色
- 新增角色管理界面，可管理 9 个角色皮肤与最多 3 个携带纪念品
- 已建立 3 个角色：波尔（均衡）、荧荧（轻盈）、泡泡（亲水），每人 3 款皮肤并拥有不同能力
- 已建立本地账号系统：多账号独立存档，支持创建、切换、修改昵称与删除账号
- 已升级为服务器账号系统：支持昵称+密码注册登录、跨设备同步存档、唯一昵称校验
- 注册账号 30 分钟内可修改昵称，30 分钟后昵称锁定
- 首次进入可选择游客模式或注册账号；游客模式仅保存在当前浏览器会话，关闭后清除
- 默认昵称从 1000 个科幻风格唯一名字池中随机抽取
- 首次进入游戏必须选择难度，选择后锁定，只有清空记录才能重新选择

- 每章进入前会播放领域大咖教学动画，含知识讲解与简单互动问答，可跳过
- 终末之诗已加入，最终章节通关后播放诗意结局
- 已接入 16x16 像素动画：9 个角色 Sprite Sheet 与 6 个 Boss Sprite Sheet
- 角色支持待机、跑步、跳跃、下落动画，Boss 使用像素动画与受击帧
- 已通关关卡显示“实际用时/预计用时”，并按新玩家/老玩家分别估算
- 暂停菜单支持继续游戏、暂存本关进度并返回菜单，并显示皮肤动画与用户信息
- 管理员模式可以随时退出，也可以一键清空本地游玩记录
