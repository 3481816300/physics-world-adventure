# B 站宣传视频：物律远征

## 基础信息

- 时长：60-90 秒
- 比例：16:9 横屏
- 标题候选：《我把物理课做成了像素解谜游戏，完整版 9.9》
- 封面：游戏画面 + 大字“物理课救星”
- 标签：独立游戏、像素游戏、物理解谜、游戏开发、学生党

## 视频结构

### 0-8 秒：钩子

画面：一颗苹果从树上落下，切到月球上苹果缓慢落下，再切到火星上。

字幕：

> 如果物理课是这样，你还怕不及格吗？

### 8-25 秒：核心差异

画面：玩家在地球、月球、火星之间往返，跳得越来越远；同一个箱子在不同星球手感不同。

字幕：

> 这不是答题软件。
> 是真的把重力做成游戏机制，让你亲手验证 G = mg。

### 25-45 秒：玩法展示

画面依次展示：

1. 推箱子、开关、机关门
2. 隐藏法则碎片
3. 牛顿互动教学动画
4. 章节 Boss 和法则核心稳定动画

字幕：

> 推箱子、触发开关、收集碎片、挑战 Boss。
> 知识不是背出来的，是你通关之后自己记住的。

### 45-60 秒：Token 消耗展示

画面：切到开发日志或终端，右下角固定一个数字芯片。

芯片样式：

```text
CODE TOKENS
[真实Token数]
```

推荐效果：数字从 0 快速滚动到真实消耗量，持续 3 秒；旁边放一行“从 3 元预算做到现在”。

字幕：

> 这个项目从 3 元预算开始，一边做游戏，一边用 AI 开发。

### 60-80 秒：购买引导

画面：回到游戏标题，再展示第一关免费和完整版解锁。

字幕：

> 第一关免费试玩。
> 早期完整版 9.9 元，当前全部内容一次解锁，后续章节免费更新。

结尾固定画面：

```text
物律远征
支持：https://ifdian.net/a/aystwljcr
B 站：https://space.bilibili.com/589748677?spm_id_from=333.1007.0.0
购买后领取兑换码，在游戏内兑换完整版
```

## 字幕和配音

建议全程一句话配音，不要念长句子：

1. “苹果落地，不是玄学，是重力。”
2. “在地球、月球、火星来回跳一次，你就懂了。”
3. “推箱子、找碎片、打 Boss，物理课可以很好玩。”
4. “这游戏，是 AI 帮我用很少的预算做出来的。”
5. “第一关免费，完整版只要 9.9。”

## 剪辑建议

- 前 3 秒不要出现菜单，直接放苹果和跳跃画面。
- 游戏画面全部录真实第一章，不用演示稿。
- Token 芯片放到开发段落右下角，避免遮挡游戏操作。
- 最后 5 秒固定购买信息，方便观众截图。
- 置顶评论放店铺链接和兑换说明。
