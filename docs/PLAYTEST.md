# 自动试玩记录

运行命令：

```powershell
node test/playtest.mjs
```

该脚本启动无头浏览器，逐个进入第 1 章关卡，模拟“持续向右 + 遇到缺口跳跃 + 遇到箱子开关推箱”的简单操作。

## 已修正的问题

- 角色移动速度过低：原速度导致操作反馈很慢，已改为更接近平台游戏的像素/秒速度。
- 第 1-1 关缺口过宽且容易误判：已合并地面段，让教学关更稳定。
- 第 1-8 关地面缺口过窄：已连接地面段。
- 开关门容易被箱子推过头后重新关闭：教学关与组合关的开关改为触发后保持开启。
- 移动平台在无垂直移动数据时产生 NaN：已做兜底。
- 生命耗尽与深渊坠落分别记录死亡次数。

## 说明

自动试玩是“可完成性”检查，不代表人类通关路线。玩家可以通过收集星星、寻找隐藏残片和探索不同路线获得更高评价。
