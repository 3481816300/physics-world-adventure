# 设计文档摘要

## 世界观

22 世纪末，人类发现现实由“法则引擎”维持。引擎故障后产生“法则裂隙”，物理法则开始互相崩解。玩家扮演“法则修复局”特工，进入不同维度碎片，稳定“法则核心”，阻止现实进一步崩塌。

## 章节结构

| 章节 | 艺术名——章节 |
|---|---|
| 1 | 风起 · 万物初动——运动与力 |
| 2 | 余响 · 涟漪成歌——波动与声学 |
| 3 | 余温 · 万物知冷暖——热学与统计 |
| 4 | 流光 · 镜里山河——光学 |
| 5 | 浮沉 · 一苇可航——流体力学 |
| 6 | 守恒 · 天地有衡——功与机械能 |
| 7 | 巧构 · 四两拨千斤——简单机械与机构 |
| 8 | 灵犀 · 电引万物——电磁学 |
| 9 | 不期 · 一撞惊鸿——碰撞与动量 |
| 10 | 星河 · 众星有约——天体物理 |
| 11 | 聚散 · 微尘有光——核物理 |
| 12 | 未定 · 万物皆可能——量子力学 |
| 13 | 永恒 · 刹那之间——相对论 |

核物理、量子力学、相对论为隐藏章节。通关主线后解锁核物理与量子力学；通关二者后解锁相对论。隐藏章节解锁前计入进度总数，但不显示在章节地图。相对论之后是独立的“熵之终章”。

## 游戏模式

- 简单模式：完成第 1-9 章即视为完整通关，`9/9`
- 完整模式：完成全部 13 章与终章，`13/13`
- 炼狱模式：取消教学关，检查点与血包减少，敌人更快，限时更紧

## 全局关卡模板

1. 教学关：无敌人，不可携带道具，不限时，自由探索
2. 知识关：一关讲一个经典物理知识点，可携带道具，少量环境敌人
3. 组合关：与已学机制轻组合，为章节 Boss 热身
4. 章节挑战/Boss：可携带道具，但关卡内无血包

每关内容后续按实际知识点数量设计，总量控制在 90-100 关左右。

## 星级系统

计划为 5 星：

- 通关
- 集齐全部能量碎片
- 死亡 3 次以内通过（炼狱模式为无伤通过）
- 发现隐藏法则残片
- 宽松限时内通过

## 道具与物品栏

每关开始前选择：

- 主动道具 / 特殊消耗品槽：最多 3 个
- 药水槽：最多 3 个

主动道具包括法则脉冲、相位护盾、时滞装置、重力反转器、锚定钩锁、复制棱镜、氧气罐。特殊消耗品包括不死图腾、金胡萝卜、金苹果。药水包括跳跃提升、移动加速、磁力增强、二段跳。

章节会禁用与本主题无关的道具，例如无水章节禁用氧气罐，光学章节禁用移动加速。

## 管理员模式

管理员模式用于开发和测试：

- 解锁全部章节与关卡
- 暴露隐藏章节
- 可任意顺序进入关卡

密码不区分大小写、全角半角与空格，避免输入法状态影响验证。

## 最终 Boss

终章“熵之终章”为独立章节。Boss 会随机抽选已通关章节的知识点，生成不同形态；玩家需要结合对应机关、道具与技能依次击败不同形态，最终用质点大炮命中熵的核心。
